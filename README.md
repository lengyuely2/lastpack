# LASTPACK · 背包求生

当前营地界面：薪火传承 / Legacy，包含生存研修、命运锻炉、幸存者、出征整备和远征纪事。四名角色具有不同的像素模型，选择卡与战场共用同一套像素；队伍颜色保留为臂章与地面标记。整备卡显示已解锁装备的图标，未解锁内容显示锁与“？？”。玩家菜单已收掉演练和演示入口，锻造仅展示实际支付金币后的服务器结果；指南与页面说明缩为必要信息，历史统计在远征纪事中查看。下方较早的功能记录可能包含已移除的演练入口。

中英文切换：主菜单右上角、对局 Esc 菜单选择“中文 / English”，设备会记住选择。菜单、奖励、27 种普通武器及 108 条品质介绍、9 种融合武器、44 件配件、成长/成就、怪物及战斗提示均有英文显示；英文笑点按语境改写，玩家自己的呼号保持原样。首次试玩可使用 `?lang=en` 链接，已有语言偏好优先。

免费部署配置已放入 `render.yaml`：仅创建一个 Free Node Web Service，不创建付费磁盘或数据库。连接 Render 并部署的步骤见 [免费部署说明](docs/DEPLOYMENT.md)。免费演示服可能休眠和丢失服务端存档；代码配置不代表已经公开上线。

开局体验更新：正式远征前 45 秒的普通怪优先在安全距离进入射程，前 90 秒普通怪生命逐渐恢复到原有水平；所有升级仍来自击杀后的经验拾取，等级经验需求和稀有品质概率保留。自动走位按装备火力与近战、散射、控制、爆炸类型选择距离，较弱的短程副武器不会独占走位决策；危险预警优先逃离，保守模式仍守住区域。

战斗新增自身受伤来源、低生命提示、身处攻击预警区时的倒计时；屏幕受伤边框只响应自己受伤。结算展示前三项实际伤害占比、本局首次发现的装备、最后受伤原因和下一个真实解锁目标，可“再来一局”回到准备阶段。

主菜单改为缓慢转动的像素墓园场景，通过下方“出征 / 成长 / 图鉴 / 设置”切换入口，也可用左右方向键切换。点击“开始出征”再选择单人或组队，其他工坊与演练收进“营地菜单”。

进入对局后战场铺满窗口，只保留生命、经验、时间和必要按钮。按 B 打开背包、C 查看属性、Esc 打开或关闭菜单，也可点击右下角按钮。单人战斗查看弹窗时暂停，关闭后继续；多人查看时战斗继续。升级奖励仍自动弹出，原有移动与自动攻击方式保留。

本轮体验更新：22 项成就与收集图鉴。默认只解锁小手枪，正式获得武器/配件后永久点亮；未发现内容隐藏图标、名字和详情为“？？”；奖励预览仍显示即将领取的内容。旧存档从最近出征记录恢复已知装备，不凭空解锁全部。成就战绩在结算时保存，收集目标发现时即时保存，演练不解锁。顶部“成就 / 体验”查看进度并设置快速揭晓、配件先暂存。首次撤离后开放白板打工人和医务室停业两种挑战，由房主出发前选择。

奖励会提示派系下一阶段和双武器连携机会；我方特效强度与伤害数字密度可分别设置，敌方弹丸和危险预警仍完整显示。首领第二阶段起每三次施法增加一条有 1.8 秒预警的追猎线。熔炼仍全凭运气、材料不保底，但高级品质更稀少，不再四档等概率。

单人进行中的对局可“保存并离开”，回到首页选择“继续上次出征”；浏览器保存恢复凭据，服务端保存生命、物品、待领奖励与三组随机数状态。所有房间每 10 秒保存一次检查点，服务重启后可重连；异常退出可能回退最多一个检查点周期。暂停/恢复房间离线保留 24 小时，普通离线房间仍为 30 分钟。多人不支持全队随时暂停，升级仍等待在线队友选择，可分别开启现有自动领取设置。

新增旧武器熔炼：在备用区手选 3 把武器换一个随机配件，或选 5 把换一把随机普通武器。四档品质按独立权重随机，材料品质、玩家等级、幸运、升级偏好与封禁均不影响产出；神铸首领融合武器不在产出池。材料会消耗，新武器留在备用区，不强制替换或合成。战斗中配件先入储物区，准备/升级时可自动放入能容纳的背包位置；储物区满时先整理再炼。顶部“熔炼工坊”提供独立免费演练。

新增完整远征循环：四个派系按 2 / 4 / 6 种有效配件激活，六件解锁血色回响、爆炸谢幕、幻影反击或魔力超载。不同武器可触发碎冰礼花、蒸汽超载、破甲追击，单人双武器和队友之间均可配合。

每局提供 3 次重抽、2 次封禁、2 次跳过换重抽；升级转轮和背包侧栏均可操作。普通放弃奖励不补回重抽。每 4 分钟出现可选风险事件：诅咒挑战、代币补给、付血冒险宝箱。本人每 20 击杀获得 1 枚事件代币，和局外金币独立。自动奖励不会替玩家决定事件风险。

局外“远征装备”按战绩解锁起步魔杖、霰弹枪、冰霜法杖及三种遗物。地图由房主出发前选择，实验室有周期酸池，废城有实体断墙。无尽每 5 分钟选择叠加词缀或撤离；进度面板和结算记录展示派系、连携和伤害来源。顶部“派系 / 连携演练”可以免费试看。


升级配件按当前两把主武器加权抽取：先用原有等级规则抽品质，再从同品质道具中抽取。特别适配的配件相对权重为 4、通用火力配件为 2、其他道具为 1；这不是固定中奖概率。法器偏向魔法配件，爆炸武器偏向爆炸增幅，有弹匣的枪械偏向弹量/装填，近战/吸血偏向续命，高射速偏向灼烧和走位，控制/暴击/成长武器也有对应倾向。实际装备配件带来的爆炸等机制也计入适配。两把武器取较高适配权重，不重复叠加；备用武器不计入。已经出现的奖励不会因换武器重新抽取，升级和首领宝箱都应用同一规则，其他流派始终可出现。

新增 12 件流派道具，总计 44 件：回血（保温杯、创可贴、浓汤）、爆炸（樱桃、烟花调料、煤气罐遗书）、闪避（拖鞋、概率伞、兔子脚）、魔法（小抄、符文锅垫、魔力汽水）。图鉴支持流派筛选与搭配指南，自动奖励设置支持爆炸、闪避、魔法偏好。

新增雷云水晶球、陨石点菜单、冰箱管理员法杖，总计 27 种普通武器。法器自动施法、无需装填；原有火焰魔杖也接受魔法配件。魔法与枪械共用两把主武器限制，通过升级获取并使用相同的四档品质。陨石可同时受魔法与爆炸增幅。

新增四组相邻配方，共 12 组：保温杯 + 创可贴增加治疗；樱桃 + 烟花调料扩大爆炸；闪避拖鞋 + 概率伞增加闪避；魔法小抄 + 锅垫增强同一法器。闪避上限 45%，闪避回血基础值上限 12；爆炸范围增幅上限 80%、溅射增幅上限 100%；法术范围增幅上限 75%、汽水施法加速上限 60%。配件占用有限背包空间，部分有移速或伤害代价。

普通武器品阶：淬火 → 精炼 → 辉耀 → 传说；首领融合武器为神铸。品质颜色和数值保留。

背包提供 12 种相邻配方和 4 种星位规则。眼镜前方接受同武器配件增加暴击；午餐盒上方接受食物增加治疗；冰箱贴四周接受成长道具增加经验；冷库边缘增幅武器配件。旋转改变星位方向，同一目标不会因为覆盖多个星位重复增幅，储物区不生效。正式背包显示星位、联动高亮和实际属性贡献。

顶部“背包工坊”提供独立演练，可拖动或点选后点击空格、旋转、切换武器绑定，实时查看联动和属性。演练道具不会进入正式背包或改动成长档案。

一个 2D 俯视角、可选择自动或手动移动的背包构筑合作游戏。单人或 2–4 名真人组队，从一把淬火小手枪开始，最多装备两把主武器，把奖励配件放进 6×5 格背包，在尸潮中构筑成长，迎战 10 / 15 / 20 分钟的三名首领，完成撤离后可继续无尽模式。

## 运行

需要 Node.js 22 或更新版本，以及 npm 或 pnpm。

```sh
npm install
npm start
```

打开 http://localhost:8787。创建组队房间后，在另一浏览器窗口加入，或让同一局域网内的手机访问运行电脑的 IP 地址与 8787 端口。Windows 防火墙可能需要允许 Node.js 的局域网访问。

本机依赖已安装。Windows 上双击 `Play.cmd` 即可在后台启动服务并打开游戏。也可在 PowerShell 的项目目录运行 `./Start-Game.ps1`。脚本会寻找系统 Node.js 或本机 Codex 附带的 Node.js，服务已经运行时不会重复启动。若默认端口被系统保留或占用，启动器会自动选择可用端口，并将地址显示在启动窗口；当前本机使用 http://localhost:8793。也可用 `./Start-Game.ps1 -Port 8793` 指定端口，局域网访问请使用实际启动端口。关闭浏览器后服务继续运行；电脑重启后再次双击启动即可。

```sh
npm test
```

## 玩法

- 武器通过升级奖励获取：淬火 → 精炼 → 辉耀 → 传说。重复武器默认保留；玩家可自愿将两把同类同品质武器合成高一级，传说封顶。满槽的新武器进入备用区，可替换装备，旧武器保留。
- 每次升级提供已有武器类别、另一种武器、随机道具三选一。两种武器和道具品质均随等级抽取；已有武器选项不会低于当前品质，同类同品质仍可合成。武器槽不占背包格子，配件仍需放入背包。
- 点击配件再点击网格，或直接拖动放置。按 R / 点击旋转可以改变物品方向。
- 武器配件可指定强化武器 01 或 02；角色道具无需绑定，可提供再生、治疗、减伤、反伤、经验和吸附加成。
- 冰箱里的小蜗牛强化与它边缘接触的武器配件，效果增加 30%，不重复叠加。
- 储物区配件不生效。可以取出、丢弃、赠送给在线队友。
- 击杀掉落经验球：普通僵尸蓝色 +1 XP，奔跑僵尸绿色 +5，强壮僵尸红色 +20，尸王红色 +100。角色自动拾取；多人同队每人获得相同经验，不抢最后一击。
- 升级需求按当前等级 L 计算：`5 + 5 × (L−1) + floor((L−1)² / 2)`。从 1→2 开始依次需要 5、10、17、24、33 XP，继续递增；这是为本游戏调整的数值。
- 经验满后升级并暂停战斗，每级获得一次武器 / 配件三选一。武器默认装备或存入备用区；也可直接选择“领取并合成”，道具自动放入背包（尝试两种方向，不移动已有物品；无空间则存入储物区），全体在线玩家选完奖励即自动恢复同一波战斗，不重置时间或生命；已有武器弹药保留，获得或合成的武器重新装填。一次连升多级会依次提供每次奖励。
- 多余经验、等级、未领取奖励跨波次保留。每波结束自动收集地上剩余经验，波次通关不额外发配件。新一局等级和经验重置。
- 每名玩家可独立选择自动或手动移动，准备 / 升级 / 战斗中均可切换。手动模式只控制方向：电脑 WASD / 方向键，触屏方向摇杆；没有开火、瞄准、技能、冲刺或拾取操作。不输入时站立，瞄准、射击、装填、治疗与附近经验拾取始终自动。倒地角色附近有存活队友持续 4 秒即可被救起。
- 手动输入按角色移动速度计算，斜向不加速；松开、失焦、升级暂停或断线清空输入。断线保留所选模式，手动角色停住，自动角色继续自动战斗。切换模式不取消准备；重开本局保留模式，重新加入新房间使用浏览器保存的选择。
- 正式游戏为 20 分钟墓园撤离，波次自动衔接，保留生命、弹药与累计战斗时间。20 分钟出现最终首领，击败并领完最终宝箱后成功撤离；小队全体在线成员选择继续后进入无尽模式，保留构筑、生命和累计时间。首领首次 10 分钟出现，之后在 15、20、25 分钟依次出现，升级暂停和未开战时间不计入。首领死亡掉落 100 XP 和一个宝箱，小队存活成员恢复 30 HP；角色走近宝箱自动开箱，小队每人额外获得一次三选一；全体倒地失败，可重开。

## 实现与当前范围

原生 HTML/CSS/Canvas 前端 + Node.js HTTP / WebSocket 服务端。战斗、背包验证、奖励、赠送和准备状态由服务端权威计算。二十七种基础武器、九种首领融合武器、四十四种道具、普通 / 奔跑 / 强壮怪物与尸王。地图、人物与装备图标为原创代码绘制；怪物使用本地保存的 CC0 像素动画素材，无需访问外部图片服务器或字体服务。

武器包含小手枪、左轮、突击步枪、霰弹枪、冲锋枪、狙击枪、激光枪、火箭发射器、加特林、匕首、长矛、冰冻发射器，以及弹弓、手里剑、十字弩、电击枪、火焰魔杖、火焰喷射器、闪电匕首、仙人掌棒、剪刀、幽灵斧、扳手和粉碎枪。激光 / 长矛可贯穿，火箭 / 霰弹枪有范围伤害，匕首 / 长矛为无需弹药的近战，冰冻控制可配合加特林增伤。合成结构参考 [Brotato 武器规则](https://brotato.wiki.spellsandguns.com/Weapons)，属性和数值为本游戏的独立平衡设定。

房间和角色会话在内存运行，每 10 秒保存服务端检查点，重启后可恢复。离线房间 30 分钟后释放。断线会自动尝试恢复角色；有在线队友时离线角色仍自动攻击，自动移动模式继续走位，手动模式原地等待。开局后不接收新角色，仅允许原角色恢复。

当前为本地原型，尚未公开部署、未提交比赛。跨网络邀请需要将整个 Node 服务部署到支持 WebSocket 的公共主机并使用 HTTPS；仅上传静态文件不能运行多人房间。不要将 localhost 链接作为参赛链接。

没有账户系统、公共匹配或大规模压力测试。局外成长持久保存，进行中的房间有服务端检查点，浏览器恢复凭据保留时可继续未完成的一局。房间邀请码仅用于邀请，角色恢复凭据单独存于当前浏览器的 sessionStorage。

## 奇异武器

顶部“武器图鉴”可按类型筛选 27 种武器，并预览四种品质的属性和特殊机制。图鉴只用于查看，武器仍通过升级奖励获得。

- 弹弓：按品质弹跳 1–4 次；手里剑：暴击时弹跳；十字弩：高暴击贯穿。
- 电击枪：范围减速；火焰魔杖：持续灼烧；火焰喷射器：扇形范围灼烧。
- 闪电匕首：近战后连锁闪电；仙人掌棒：命中发射 3–6 根尖刺并击退。
- 剪刀：按实际造成伤害吸血 12–24%，不能超出最大生命。
- 幽灵斧：每 8 / 7 / 6 / 5 次自身击杀获得本局永久 +2% 武器伤害，上限 +60%；换武器保留，新局重置。
- 扳手：每个装备槽每波部署一座炮台，白 / 蓝 / 紫 / 红对应弹丸 / 燃烧 / 激光 / 爆炸。升级暂停时炮台也暂停，移除扳手后炮台移除。
- 粉碎枪：快速爆裂弹，小范围爆炸。

类型与机制参考 [Brotato 弹弓](https://brotato.wiki.spellsandguns.com/Slingshot)、[电击枪](https://brotato.wiki.spellsandguns.com/Taser)、[扳手](https://brotato.wiki.spellsandguns.com/Wrench)及武器图鉴；本项目独立绘制图标 / 特效并调整数值，不复制原作素材或完整平衡表。

## 空背包与怪道具

开局及重开均为一把淬火小手枪、空第二槽、空背包与储物区。44 种道具只能通过升级奖励取得；顶部道具图鉴显示名称、占格和实际效果。获得后放入背包才生效。

道具参考《土豆兄弟》的古怪风格，数值按本游戏独立设计。部分有副作用，例如悲伤番茄提高再生但降低生命，独眼虫的遗嘱提高伤害但缩短射程。小队经验加成取所有角色的最高装备加成，额外经验的小数保留至后续拾取；减速光环取附近存活队友的最高加成。

## 画面平滑

服务器仍以每秒 10 次发送权威战斗状态。浏览器将玩家、敌人、经验和炮台位置在快照之间插值，约 110 毫秒画面缓冲，不改变战斗判定；暂停、换波次、换房间立即显示新状态，不复活已删除对象。伤害文字等特效按浏览器时间平滑衰减。战斗中的装备与队伍面板最多约每秒更新 5 次，阶段和移动模式变化立即显示。实际渲染帧率取决于设备和浏览器。

## 像素美术版本

战场为原创像素墓园：480×310 内部画布放大至 960×620，并关闭图像平滑；地图背景和角色帧缓存，延续位置插值。披风幸存者按小队颜色区分，普通僵尸、奔跑僵尸、强壮僵尸与尸王使用不同像素形象。经验宝石、击中、爆炸、连锁闪电、灼烧、治疗和倒地状态使用像素特效；武器与道具图标统一为缓存的像素轮廓，界面采用夜紫与暖金的方形边框。没有使用《吸血鬼幸存者》的原始素材。

## 怪物动画与进阶

采用 stealthix 的 [Animated Monsters](https://opengameart.org/content/animated-monsters)（CC0）：僵尸、骷髅和女巫的行走、攻击与倒地帧。本地原始素材和许可记录保存在 `public/assets/monsters/`，前端缓存动画帧并采用最近邻缩放。

正式生存局的普通僵尸在第 4 分钟变异、第 8 分钟进阶为精英。第 2 分钟解锁冲刺骷髅、第 4 分钟解锁砸地尸卫、第 6 分钟解锁远程术士；各自技能有地面预警或施法蓄力。怪物强度按战斗分钟平滑增长，普通怪物生成数量受上限控制。顶部“怪物图鉴”可查看外观与行为说明。

## 武器弹体与射击效果

普通枪械显示飞行子弹、枪口闪光、抛壳和命中火花；左轮弹更粗、狙击尾迹更长，连发武器按实际攻击频率显示。霰弹显示七颗散弹，激光贯穿光束，火箭显示弹体、尾焰、烟迹和爆炸；冰弹、火球、扇形火焰、电弧、弩箭、旋转手里剑、石子和仙人掌尖刺都有独立像素效果。近战显示挥砍、长矛刺击和剪刀双刃，弹跳 / 连锁特效分段揭晓。炮台四品质分别显示弹丸、火球、激光和火箭。

武器图鉴 →“查看射击效果”可循环比较十二种表现。正式战斗使用服务端生成的攻击事件，浏览器按事件寿命播放；伤害仍按原有即时判定，弹体飞行是视觉动画，未改变弹药、射速、范围和伤害规则。绘制使用有数量上限的像素图元，无外部图片和额外资源下载。

## 自愿合成、卸下与武器趣味描述

同类同品质奖励默认保留：空槽时装备第二把，满槽时存入备用区。奖励下方单独的“领取并合成”会立即消耗这次奖励升级已有武器，仍自动继续战斗。备用武器的“装备”和“合成”是两个独立操作。两把已装备重复武器可点击“自愿合成”。

武器卡“卸下到备用区”保留种类和品质；备用区的“丢弃”彻底移除。战斗中也可卸下、装备和自愿合成，背包仍锁定。至少保留一把武器，备用区最多 12 把。27 种武器在白、蓝、紫、红四个品质分别拥有独立搞怪介绍，共 108 条；装备卡、升级奖励和武器图鉴均随品质显示对应介绍。小手枪从“没睡醒”到“喝了两杯”“升职”“退休返聘”，实际属性与机制另列，介绍不改变数值。

## 像素音效

音效使用原创 Web Audio 合成，首次点击或按键后启用，不下载外部音频。顶部“音效”提供 28 个试听按钮、音量与静音，设置保存在本机。普通/高级经验拾取音色不同，连续拾取逐步抬高音调。27 种武器按枪械、激光、冰弹、电击、火焰、投射及近战生成音色；换弹、暴击、爆炸、死亡、治疗、成长、倒地、复活、装备/合成、波次、通关与失败都有反馈。

怪物进场按种类和普通/变异/精英等级区分，尸王使用低频警报；战斗中间隔播放怪物叫声。升级有上行旋律，奖励转轮有节奏，跳过/关闭会取消转轮剩余音符，揭晓和成功领取另有提示。多人队友攻击声音较轻，并按场上位置左右定位。重复快照不会重复播放，重连/新房间不会重播历史事件；声音有频率与并发上限、压缩器，切到后台、静音或离开时清理声音。

## 定时首领、组合与显示设置

正式服务端使用连续生存模式；旧六波模式仅保留为既有模拟回归测试。累计战斗时间只在 battle 且有在线玩家时推进，服务器暂停升级时首领计时、预警和敌方弹丸均暂停。首领依次为墓园钟主、铁棺暴君、红月审判官并循环，初次生命 1500，之后每次 +600，再乘在线小队人数。生命低于 65% / 30% 进入第二 / 第三阶段，召唤护卫并提高施法频率。落点、环形震荡和延迟弹幕按首领变体更换起始顺序，配有各自颜色、环绕粒子、进场与阶段公告、大血条和音效。顶部“首领演练”提供独立无限生命观察场，可切换三个首领和三个阶段。

背包里共享一条边的配件触发组合，斜角或储物区无效，武器配件须绑定相同武器，每种组合每个目标最多一次。五种配方：违章电咖啡（攻速 +12%）、香肠火锅（灼烧 +4/秒）、酸到复活（治疗效果 +15%）、经验收税局（吸附 +25 / 经验 +5%）、尿布防爆工事（最大生命 +15 / 减伤 +5%）。装备区列出已生效组合，相关道具有绿色边框，组合配方可直接查看。长局库存满时可放弃本次补给，正常消耗该次选择并自动继续，不发额外物品。

画面设置提供轻量 / 均衡 / 丰富特效、30 / 60 FPS 上限、数字与实时帧率显示，保存到本机。危险预警及敌方弹丸不因低特效关闭，显示设置不改变服务端战斗。服务器每个 tick 缓存人物属性，常规选敌改用线性扫描；特效最多 320 个、预警 32 个、敌方弹丸 96 个，大量经验按种类合堆并保留经验与拾取治疗次数。客户端补间敌方弹丸，后台停止绘制。

## 完整单局与战斗反馈

墓园撤离：10 分钟墓园钟主，15 分钟铁棺暴君，20 分钟红月审判官。时间指实际战斗时间，升级和准备不计时；最终首领战可以超过 20 分钟，领取最终宝箱后才通关。最终战停止生成普通怪物，完成后不会继续自动生成首领，选择无尽模式后恢复每五分钟一名首领。

前期基础远程火力 +10%、基础移动速度 +8。每次完成补给后，存活角色获得 3 秒伤害 ×1.7 / 射速 ×1.25 的火力爆发及 1 秒保护；普通受击后有 0.35 秒保护，防止同一瞬间被多只怪物叠加击杀。保护同时作用于接触、技能和敌方弹丸。每 25 次小队击杀掉落一份 +8 生命补给，必须走近拾取，满血不浪费补给。

每 90 秒一轮压力变化：末段尸潮爆发，下一轮开始有 10 秒暂停普通刷怪，已有敌人继续活动。第 3 分钟开始每 2 分钟出现精英挑战，轮流为夺命外卖员、违章拆墙队长、欠费雷电法师，强化生命、速度或弹速，带橙色光环和入场预警；掉落 +10 / +30 精英经验。首领战保留原有三阶段技能。

受击亮闪、暴击数字、负伤提示、地面补给和每 25 连杀提示提供反馈。连杀需 3 秒内延续，仅用于反馈和纪录，不额外提高伤害。减少动态效果偏好禁用角色保护闪烁；轻量画面仍保留危险预警。

背包详情显示移除与放入该道具后的实际属性差异，以及触发的组合。储物区道具会尝试两种朝向并预览可行位置；“自动找空位”由服务端核验，放不下时保留物品。已有道具不自动搬动。

## 自动策略、背景音乐与首领加强（2026-10-07）

顶部“自动设置”可独立选择自动走位策略和自动领取奖励。默认保留均衡走位、手动奖励；激进模式积极追经验、宝箱和受伤时的补给，保守模式以切换时的位置为守点，在 140 范围内拾取，受威胁时退避，安全后返回。手动移动继续只有方向控制，攻击和拾取自动进行。重开与刷新保留偏好。

自动领奖可调等待时间、火力 / 续命 / 成长 / 均衡偏好、武器种类、培养已有武器、自动换装、同品质合成、首领融合以及满库存处理。服务端核验实际奖励、空间与配方，并在 2–10 秒后领取；倒计时中仍可手选或关闭自动。换下的武器进入备用区。合成和融合默认关闭，满库存默认等待整理，不自动丢装备。每位队友独立设置，全部在线队友领完后立即继续战斗。

“声音”里分别控制原有音效与新增背景音乐。原创四小节像素旋律覆盖营地、普通战斗、尸潮、首领、升级、撤离和失败七种场景，在小节边界切换。首次点击解锁播放，标签页隐藏停止调度，回到页面恢复；音乐音量及静音独立保存，调度器限制同时声部，避免叠曲。

正式战役三名首领单人生命为 5200 / 7800 / 10400，随在线人数线性增加（之前为 1500 / 2100 / 2700）；近战伤害 28、移动速度 25。技能每 4.8 / 3.6 / 2.5 秒施放，对应三阶段。钟主连续落点轰击与环形弹幕；铁棺暴君预警冲锋后震地；红月审判官旋转弹幕与定向扇射，狂暴时追加落点。阶段阈值仍是 65% / 30%，首次 10 分钟、之后每 5 分钟和宝箱奖励规则保持一致。独立首领演练使用正式攻势。

自动躲避改为评估 16 条逃生方向，防止重叠预警相互抵消；环形攻击只把环带视为危险，中心可安全站位。弹道、光束、斩击、暴击火花和爆炸冲击波增强，并按品质区分拖尾颜色；轻量画面与减少动态效果会省去额外层。危险边界绘制在友方特效上层。火力演示可选白到红品质。

## 尸潮火力表现

武器图鉴 → 查看射击效果，可观看六种传说双武器的尸潮演练，并逐件对比淬火、精炼、辉耀、传说品质。近战扫弧、喷火锥、分叉电光、激光光带、投射物残影与爆炸火团随品质增强；轻量画质与减少动态效果会跳过这些附加层。特效按照实际攻击方向、射程和爆炸半径绘制，危险边界仍在友方特效上方。

## 金币锻造

局外成长 → 金币锻造：选择十二项永久强化之一，用金币尝试升阶，最高 5 级；原有零件训练仍可稳妥升一级。锻造可升一级、直达满级、保持或降一级，等级不低于 0；满级项目不再收费锻造。本局开始后加成锁定，锻造的升降在下一局生效。补给站尚未准备时即时生效；有人准备后须先取消准备。

锻造界面不显示概率表。等级转轮在 0–5 级之间跳动，先快后慢，停稳后揭晓服务端已保存的结果。每项强化都有免费转轮演练，演练不扣金币、不改变档案。

正式对局杀怪时概率获得金币：普通怪 12%，精英 45%，首领 100%。击杀处出现金币弹起和提示音，自动收入本局钱包；未离队的每位成员共享基础金币，各自再按收益强化结算。普通每次掉落为 `round(2 × (1 + min(存活秒数, 1800) / 300)^1.35)`，强壮怪 ×2、精英 ×3、首领 ×8（取最高类别，不叠乘）。普通怪在开局 / 5 / 10 / 20 分钟分别掉 2 / 5 / 9 / 18 金币；后期杀怪更快也会增加总收入，30 分钟后单次倍率封顶。

失败、主动撤回、撤离都会结算金币；无尽模式继续累计，按同一局已结算差额入账。刷新后可恢复未结束的房间。金币与原有零件分别存档；锻造服务端抽签、原子保存，重复请求不重复扣费。
